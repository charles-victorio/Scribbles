# scribbles

Unpolished quick demos & artifacts. Static site, built with `build.js`, deployed on Cloudflare Pages.

Run locally: `npm run dev`

Build to save changes: `npm run build`

## Adding a project

1. **Add an entry to [scribbles.toml](scribbles.toml):**

   ```toml
   [[project]]
   slug = "my-project"
   name = "My Project"
   description = "One sentence about what this does."
   url = "https://example.com"   # OPTIONAL — omit for a local project (see step 4)
   ```

2. **Add a thumbnail:** `thumbnails/my-project.webp`

3. **Add a writeup (optional):** `writeups/my-project.md` — plain markdown, no front matter needed. If you skip this, the card just won't show a "Read more" link.

4. **Add the project itself, if it's not an external `url`:** `projects/my-project/index.html`, plus any other files it needs (css, js, images, video — reference them with relative paths, they'll work). It'll be reachable at `/my-project` on the live site.

5. **Preview:** `npm run dev` — builds and serves via `wrangler pages dev`, which is the only way to see the real routing behavior locally (a plain static server won't honor the clean-URL rewrites).

6. **Ship it:** push to `main`. Cloudflare Pages auto-builds (`npm run build`) and deploys.

## Notes

- `slug` must be unique and can't be one of: `writeups`, `thumbnails`, `projects`, `style.css`, `index.html` — the build fails loudly if it collides.
- Files are matched to a project purely by `slug`, so rename with care — you'd need to rename the thumbnail/writeup/project folder to match.
- `dist/` is generated by the build and gitignored — never edit it directly.
